# Invisible Cadence

Getting to grips with AI and automation on my own terms, and using them to take some of the load out of ordinary, everyday life.

The aim is not maximum productivity. It is fewer things to remember, so there is more time for the things that matter.

## Projects

| Project | What it does | Status |
| --- | --- | --- |
| [buying-list](https://github.com/invisible-cadence/buying-list) | A shared household buying list, installed on your phone, that tracks things from idea to bought and does the product research for you. | Building |

**Building** means approved and in progress. **Live** means in everyday use. **Parked** means on hold, with a line on why.

## How these are built

- Each project has its own repository, public from the first commit, so the history shows how it grew.
- Each one carries its own roadmap, and a record of the decisions behind it and what else was considered.
- The code is written with AI coding agents and reviewed one pull request at a time. The rules the agents follow are in each repository's `AGENTS.md`.
- Tools are chosen to fit the problem, with a preference for free tiers and for keeping things simple.
